# Экспертная система диагностики вредоносного ПО

Десктопное приложение на Python с Tkinter для диагностики компьютерных вирусов и вредоносного ПО на основе экспертной системы.

## Функциональность

- **Редактор базы знаний**: Позволяет экспертам добавлять и редактировать классы вредоносного ПО, диагностические признаки и их значения.
- **Система ввода данных**: Пользователь вводит значения признаков, система диагностирует класс ПО.
- **Интеграция с LLM**: Генерирует объяснения диагноза с помощью OpenAI API.

## Установка

1. Установите зависимости:
   ```
   pip install tinydb requests
   ```

2. Для LLM установите переменную окружения OPENAI_API_KEY с вашим ключом API.

## Запуск

```
python app/main.py
```

## Структура

- `main.py`: Главное приложение с GUI.
- `knowledge_base.py`: Модуль для работы с базой знаний (TinyDB).
- `diagnostic_engine.py`: Логика диагностики.
- `llm_helper.py`: Интеграция с LLM.
- `data/`: Папка для хранения базы данных.
