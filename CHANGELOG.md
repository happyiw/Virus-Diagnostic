# Changelog

## v2.0.0 (2026-05-07)

### Новые возможности

#### UI/UX
- ✅ **Разделение полей мин/макс**: Поля ввода диапазонов теперь разделены на два отдельных поля для мин и макс значений в редакторе базы знаний

#### Машинное обучение
- ✅ **Decision Tree Classifier**: Реализована собственная ML модель на основе Decision Tree
- ✅ **Датасет**: Создан датасет из 7500 образцов с равномерным распределением по 11 классам
- ✅ **Подготовка данных**: Модуль `DatasetPreparer` для подготовки данных к обучению
- ✅ **Точность модели**: 81.12% на тестовой выборке
- ✅ **Гибридная диагностика**: Система использует ML модель с fallback на правила

#### Хранение данных
- ✅ **JSON-файлы**: Все данные (классы, признаки, значения) хранятся в JSON-файлах
  - `classes.json` - Классы вредоносного ПО
  - `features.json` - Диагностические признаки
  - `feature_types.json` - Типы признаков
  - `ranges.json` - Допустимые и нормальные диапазоны
  - `class_features.json` - Признаки каждого класса
  - `class_values.json` - Значения признаков для каждого класса
  - `dataset.json` - Обучающий датасет (7500 образцов)
- ✅ **PostgreSQL интеграция**: Подключение к PostgreSQL через SQLAlchemy ORM
  - Таблицы для хранения классов, признаков, диапазонов, логов диагностики
  - SQL скрипты инициализации БД

#### Docker
- ✅ **Dockerfile**: Контейнеризация приложения с Python 3.10
- ✅ **Docker Compose**: Оркестрация контейнеров (приложение + PostgreSQL)
- ✅ **Автоматическая инициализация**: При запуске контейнера генерируется датасет и обучается модель
- ✅ **Здоровье контейнеров**: Health checks для PostgreSQL

#### Документация
- ✅ **README**: Полная документация с инструкциями по запуску (локально и через Docker)
- ✅ **.env.example**: Пример конфигурации переменных окружения
- ✅ **.gitignore**: Расширенный файл игнорирования
- ✅ **CHANGELOG**: Этот файл
